# NWP & Meteorological Portfolio 🌍🌪️

This repository contains professional atmospheric simulation projects developed in Python, demonstrating expertise in Numerical Weather Prediction (NWP) and meteorological data visualization.

## 📊 Projects Included:

### 1. Thermal Field & Isotherms Simulation (Day 1)
* **Script:** `temperature_simulation.py`
* **Output:** `temperature_thermal_chart.png`
* **Description:** Simulates surface temperature distribution and generates professional isotherms using NumPy and Matplotlib.

### 2. Synoptic Pressure & Wind Vector Simulation (Day 2)
* **Script:** `synoptic_weather_chart.py`
* **Output:** `synoptic_pressure_wind_chart.png`
* **Description:** Simulates Mean Sea Level Pressure (MSLP) contours combined with atmospheric wind quiver vectors for synoptic analysis.

## 🛠️ Tech Stack:
* **Language:** Python
* **Libraries:** NumPy, Matplotlib, Xarray
